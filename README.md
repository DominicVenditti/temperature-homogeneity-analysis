# Temperature Homogeneity Analysis

Analyzing long-run temperature series for homogeneity and trend — detecting
breakpoints and discontinuities in climate station data.

## What this covers
- Homogeneity testing on multi-decade temperature series
- Trend and persistence analysis
- Comparison of station records over time

## Contents
- `notebooks/` — full analysis
- `data/` — temperature series + county/state CSVs
- `paper/` — final report
- `references/` — source literature
